# cone

Flat sheet-metal pattern for a conical frustum.

**Converted from:** `CONE.C` (M. W. Klotz, 10-11/01),
`MWKC/WorkshopUtilities/cone.zip`
**Go source:** `MWKGo/cone/cone.go`

## Purpose

Written to make a conical flue (a frustum of a cone) for a
Stirling engine: a flat pattern cut from sheet metal and rolled
to form the required shape. Given the frustum's small diameter,
large diameter, height, and an overlap allowance for the seam,
this program computes the flat pattern's two radii, their chord
lengths and arc lengths, and the pattern's included angle.

## Inputs

| Prompt | Default |
|---|---|
| small diameter of cone | 3.0 |
| large diameter of cone | 5.0 |
| height of cone | 10.0 |
| overlap allowance for joining | 0.25 |

## Output

The input dimensions and circumferences, then the pattern's
included angle, both radii, their chords and arc lengths, the
edge length, and the cone's own included angle.

## Method

```
coneHalfAngle = atan(0.5*(largeDiameter-smallDiameter) / height)
smallRadius = 0.5*smallDiameter / sin(coneHalfAngle)
largeRadius = 0.5*largeDiameter / sin(coneHalfAngle)
```

Both radii's arcs sweep the same included angle, derived from
the large circumference plus the overlap allowance:

```
includedAngle = (pi*largeDiameter + overlap) / largeRadius
```

The small radius's own chord uses its own, slightly different
angle, derived the same way from the small circumference plus
the same overlap allowance; because the overlap does not scale
with radius the way the circumference does, this angle is not
exactly equal to the large radius's angle, a quirk carried
forward from the original program rather than corrected, since
`CONE.TXT`'s worked example was generated by this exact
arithmetic.

## Worked Example

`CONE.TXT` gives a complete worked example at the documented
default inputs, every printed value included, which this
conversion reproduces exactly.
